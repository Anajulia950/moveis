## Descrição do Projeto
Este projeto simula um sistema de móveis utilizando conceitos de **Programação Orientada a Objetos (POO)** em Java, aplicando os conceitos obrigatórios:

- **Classe abstrata**: `Movel`  
- **Subclasse**: `Cadeira`  
- **Enums**: `Comodo` (simples) e `Acabamento` (completo)  
- **Herança**: `Cadeira` herda de `Movel`  
- **Override**: métodos `montar()` e `exibirFicha()`  
- **Overload**: método `montar(int qtdPessoas)`
